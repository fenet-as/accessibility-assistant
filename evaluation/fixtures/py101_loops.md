Loops let a program repeat work without copying code. This lesson covers the two loop statements in Python.

## For Loops
A for loop repeats a block of code once for every item in a sequence such as a list or a string. The range() function produces a sequence of numbers, so `for i in range(5)` runs the loop body five times.

## While Loops
A while loop keeps running as long as its condition is True. Always make sure something inside the loop changes the condition, otherwise you create an infinite loop that never stops.

## Break and Continue
The break statement exits a loop immediately. The continue statement skips the rest of the current iteration and moves on to the next one.
