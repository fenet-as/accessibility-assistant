Python is a beginner-friendly programming language used for automation, data analysis and web development. This lesson introduces how programs store information.

## Variables and Assignment
A variable is a name that refers to a value stored in memory. You create a variable with the assignment operator, for example `price = 20`. Variable names should be descriptive, use lowercase letters and underscores, and cannot start with a number.

## Data Types
Every value in Python has a data type. Common types are integers for whole numbers, floats for decimal numbers, strings for text and booleans for True or False values. The built-in type() function tells you the type of any value.

## Type Conversion
You can convert between data types with int(), float() and str(). Converting the text "42" with int() gives the number 42, which is useful when reading numbers typed by a user with input().
